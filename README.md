# Personal Life Tracker — Calendario Reattivo in Angular

Un’applicazione web progettata per monitorare la propria vita quotidiana attraverso un calendario interattivo. Ogni giornata può raccogliere informazioni personali come spese, attività, passioni, stati d’animo o note private, trasformando il calendario in un vero e proprio diario digitale.

Il progetto include una struttura pensata per integrare un sistema di autenticazione sicuro e modulare, utile per future evoluzioni con backend o sincronizzazione cloud. Attualmente l’obiettivo principale è mostrare un’architettura pulita, moderna e basata su Angular Signals.
## Tecnologie utilizzate

- **Angular 21.1** — Framework principale dell’applicazione, utilizzato per la gestione dei componenti, delle viste e dell’architettura complessiva.
- **Angular Signals** — Sistema reattivo moderno introdotto nelle ultime versioni di Angular, utilizzato per gestire lo stato in modo semplice, performante e predicibile.
- **TypeScript 5.9** — Linguaggio tipizzato che garantisce maggiore sicurezza, leggibilità e manutenibilità del codice.
- **Node.js (consigliato ≥ 18)** — Versione compatibile con Angular 21 per l’ambiente di sviluppo.
- **npm 11.6.0** — Package manager utilizzato per installare e gestire le dipendenze del progetto.
- **RxJS 7.8** — Libreria reattiva utilizzata internamente da Angular e per eventuali flussi asincroni.
- **Vitest** — Framework di testing moderno e veloce per eseguire test unitari.


## Installazione e avvio

Assicurati di avere installato **Node.js (versione 18 o superiore)** e **npm**.

Clona il repository:

```bash
git clone <URL-del-repo>
cd calendario-ng
```
Installa le dipendenze:

```bash
npm install

```
Avvia l’applicazione:

```bash
ng serve

```
